# design_repo

ARK（ARK ALL）前端設計物料倉庫。

本倉庫隸屬 [UM-ARK](https://github.com/UM-ARK) 組織，專門存放 APP 相關的設計資產（宣傳圖、商店海報、Logo、設計規範等），與程式碼倉庫分離維護。對應的 APP 前端倉庫：

- **APP 前端**：[UM-All-Frontend](https://github.com/UM-ARK/UM-All-Frontend)

開發與設計可各取所需：寫功能看前端倉庫，找視覺與宣傳物料看本倉庫。

## Sketch 源檔

大檔 `.sketch` **不在 Git 裡**，請到 Releases 下載：

- https://github.com/UM-ARK/design_repo/releases/tag/sketch-archive-2024-08

詳見 [`Sketch Files/README.md`](Sketch%20Files/README.md)。

## 內容概述
### Advertisement 廣告
- 最最核心的部分。
- 根據日期劃分，每個日期文件夾內包括各種設計物料，如：Posters, Screenshots,還有Videos。
- 源設計 Sketch 請改從 Releases 下載（不再放在本目錄追蹤）。

### AppStore Posters
- 根據日期劃分。
- 包括Demo Screenshots，和實際的Poster。Poster分為5.5吋和6.5吋的。

### Design Resources 設計資源
- 應用商店下載badge
- UM設計規范
- 電腦學會UX資源

### Logos
- 各種各樣的ARK圖標（持續更新中）
